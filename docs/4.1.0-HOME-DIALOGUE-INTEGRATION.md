# Nero 4.1.0 — Home Dialogue entegrasyon notları

Bu dosya 4.0.4 kaynak koduna 665 repliklik ana sayfa konuşma sisteminin **fiilen nasıl entegre edildiğini** özetler. Ayrıntılı ürün ve metin şartnamesi `NERO-HOME-DIALOGUE-4.1.0.md` dosyasındadır.

## Eklenen dosyalar

- `src/data/home-dialogues.tr.json`: 665 repliğin makine tarafından okunabilir veri modeli.
- `src/main/home-dialogue.js`: koşul filtresi, 5–10 dk scheduler, kategori/rarity ağırlıkları, son-20 anti-repeat, topic cooldown, rare pending/seen, return ve debug mantığı.
- `test/home-dialogue.test.js`: veri ve motor için otomatik testler.
- `%APPDATA%\Nero\home-dialogue-state.json`: runtime'da otomatik oluşan kalıcı Home state dosyası.

## Değiştirilen entegrasyon noktaları

- `src/main/main.js`: Home context snapshot, scheduler, backup/import, timer history hook'ları, Home IPC'leri.
- `src/main/stats.js`: günlük `timersDone` / `timersQuit` sayaçları.
- `src/renderer/panel/index.html`: eski ↻ butonu kaldırıldı.
- `src/renderer/panel/panel.js`: fade ve seen bildirimi; konuşma kartı tıklamayla boşaltılmaz.
- `src/renderer/panel/panel.css`: fade davranışı; konuşma kartında manuel dismiss/click davranışı yoktur.
- `src/preload/preload.js`: `home:seen` ve debug IPC izinleri; `home:dismiss` kullanılmaz.

## Davranış garantileri

- Panel açmak/kapatmak yeni replik seçmez.
- Home repliği uygulama normal çalışırken panelden bağımsız olarak rastgele 5–10 dakikada değişir.
- Bilgisayar kilitli veya 10+ dakika idle ise rotasyon içerik tüketmez.
- Aktif timer sırasında rotasyon ertelenir; timer sonrasında 1–3 dakika bekler.
- Son 20 replik uygulama yeniden başlatılsa da tekrar seçilmez.
- Rare/ultra-rare replik, Home ekranında görülmeden tüketilmiş sayılmaz.
- Ultra-rare görüldükten sonra aynı ID 180 gün boyunca yeniden eligible olmaz.
- Koşullu replik current iken koşulu bozulursa yanlış bağlam gösterilmeden replacement seçilir.
- Günün sözü (`QUOTES`) sistemi korunmuştur; eski `quoteOffset` / Home refresh davranışı kaldırılmıştır.
- Masaüstü karakter balonu `Dialogue` / `TALK_INTERVALS` sistemi değiştirilmemiştir.

## Debug

Uygulamayı `NERO_HOME_DEBUG=1` ortam değişkeniyle veya `--home-dialogue-debug` argümanıyla çalıştırınca Home motoru debug log yazar. Debug modunda renderer devtools/IPC üzerinden:

- `home:debugContext` → güncel koşul snapshot'ını döndürür.
- `home:debugSelect`, `<ID>` → verilen repliği test amaçlı zorla current yapar.

Normal sürümde bu iki debug çağrısı veri döndürmez / seçim yapmaz.
