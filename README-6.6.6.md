# Nero 6.6.6 kaynak paketi

Değişiklikler: `CHANGELOG-6.6.6.md`.
Doğrulama ve bilinen sınırlar: `docs/6.6.6-VALIDATION.md`.

```sh
npm ci
npm test
npm start
```

Windows kurulum dosyasını derlemek için `npm run dist` kullanılır. GitHub Actions tarafında **Build Nero 6.6.6 Final** iş akışı elle çalıştırılabilir. Bu teslimatta kurulum EXE'si bulunmaz.

Kıyafet çizimleri ve ayrı animasyonlu yüz katmanları kaynak paketin içindedir; başlatmak için yeniden görsel üretmek gerekmez. Koleksiyonu yeniden derleme bilgileri: `scripts/wardrobe-v665/README.md`.
