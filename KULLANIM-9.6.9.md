# Nero 9.6.9

Yeni görünüm: Bütçe → Finans ayarları → Finans teması → **Finans Merkezi**. Seçim hemen uygulanır ve saklanır; önceki dört görünüm kullanılabilir. Genel Nero temaları Ayarlar → Görünüm → Tema bölümündedir.

GitHub Actions → Build Nero 9.6.9 Final → Artifacts → **Nero-9.6.9-final-bundle** paketini indir. Kurulum EXE’si, blockmap, latest.yml, tam kaynak ZIP’i ve changelog içerir.

Kaynağı Node.js 22 ile çalıştırmak için `npm ci`, `npm run finance:check`, `npm run finance:build`, `npm start`. Windows kurulumunu oluşturmak için `npm run dist`.

Detaylar: docs/FINANS-MERKEZI.md. Doğrulama: docs/9.6.9-VALIDATION.md.
