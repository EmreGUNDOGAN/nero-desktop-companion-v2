# Nero 6.9.10

Actions → Nero-6.9.10-final-bundle: kurulum, blockmap, latest.yml, tüm kaynak kod ve changelog.

Nero-Setup-6.9.10.exe ile kur. Tema: Ayarlar → Görünüm → Çizgi Roman Arası. Finans ayarlarında Nero teması çizgi roman bütçesini gösterir; Finans Merkezi önceki koyu görünümü gösterir.

Kaynak: npm ci; npm run finance:check; npm run finance:build; npm test; npm start.

Sürüm numarası kullanıcı talebiyle 6.9.10 olarak ayarlandı. Önceki 9.6.9'dan daha küçük olduğu için mevcut otomatik güncelleyici bunu yükseltme olarak algılamaz; bu paketi setup ile elle kur.
