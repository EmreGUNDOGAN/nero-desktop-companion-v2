# Nero 9.6.7 kaynak kodu

ZIP'i bir klasöre çıkar. Node.js 22.12 veya üstü kuruluysa proje klasöründe terminal aç:

```sh
npm ci
npm start
```

Windows kurulum dosyasını Windows üzerinde oluşturmak için:

```sh
npm run dist
```

Finans görünümünü Bütçe → Finans ayarları → Finans teması içinden seç: Modern finans veya Nero temasına uyumlu. Aynı yerde yazı boyutu ve bildirim gün/saat ayarları bulunur.

Kullanım: `docs/BUTCE-REHBERI.md`.
Kapsam: `docs/BUTCE-TAKIP.md`.
94 dersin metni: `docs/FINANS-EL-KITABI.md`.
Test sonuçları ve doğrulama sınırları: `docs/9.6.7-VALIDATION.md`.

## Premium Black

Bütçe → Finans ayarları → Finans teması → **Premium Black**.

Seçim hemen uygulanır ve saklanır. Özet, İşlemler, Hesaplar, Bütçeler, Ödemeler, Raporlar, Takvim ve Finans Akademisi aynı koyu görünüme geçer. İşlem ve ayar pencereleri de uyumludur. Diğer üç finans görünümü seçilebilir. Genel Nero temasına geri dönmek için “Nero temasına uyumlu” seçilir.

Hesaplar sayfasındaki açıklama “Hesaplar hakkında” satırından açılır. Özet kartları hesaplar, gelir/gider işlemleri, bütçeler, taksitler ve raporlara gider. Menü aşağı kaydırılırken yerinde kalır. Menüye odaklandıktan sonra ok tuşları, Home ve End ile bölümler arasında geçilebilir.

`docs/premium-black-screens` içindeki gerçek Electron ekran görüntülerinin tutarları geçici test verisidir. Uygulama bu kayıtlarla başlamaz. Windows kurulum dosyası bu kaynak paketinin parçası değildir.
